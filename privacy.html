Privacy Policy

Last updated: October 23, 2026

This policy covers the Google application named “Data”, a personal tool used by Project Synapse. Its only user is its owner, Bryon Higbee, who uses it to access his own Google Drive through rclone running on his own computer.

What data is accessed

With the owner's permission, the app reads and writes files in the owner's Google Drive. No other person's data is accessed.

How data is used and stored

Files move only between Google Drive and the owner's own computer. The sign-in token is stored only on that computer. No data is sent to any server run by the app, and no analytics or tracking are used, including on this website.

Sharing

No data is sold, shared with, or transferred to any third party.

Google API Services

Data's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
